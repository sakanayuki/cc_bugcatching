# むしとり 仕様書

スマホ縦画面向けの 2D ドット絵虫取りゲーム。GitHub Actions で GitHub
Pages に配信する。

## 1. 技術構成

  --------------------------------------------------------------------------------------------------------------------------------------------------
  項目                                決定
  ----------------------------------- --------------------------------------------------------------------------------------------------------------
  言語/ビルド                         TypeScript + Vite（フレームワークなし）

  描画                                Canvas 2D。内部解像度 **360×640** を画面幅に合わせてニアレストネイバー拡大

  素材                                ドット絵はすべてコード内に文字列マップ＋パレットで定義し、起動時にオフスクリーン Canvas
                                      に焼き込む（外部画像なし）

  画面                                縦 640 固定。縦長のスマホでは幅 360 で、余った上下は画面端の色を延長。横長の
                                      PC・タブレットでは画面の縦横比に合わせて森を横に広げる（最大
                                      16:9、それより横長なら左右に帯）。主人公は常に画面下部中央付近に配置し、虫の数は幅に比例して増やし密度を保つ

  フォント                            DotGothic16（Google Fonts）。読めない場合はシステムフォント

  サウンド                            Web Audio API による 8bit 風の合成効果音のみ（BGM なし）。右上でミュート切替

  振動                                網を振った瞬間、捕獲成功時に `navigator.vibrate`（対応端末のみ）

  保存                                ハイスコアを `localStorage` に保存

  テスト                              Vitest（ゲームロジックの純粋関数）

  デプロイ                            `main` への push で 型チェック → テスト → ビルド → GitHub Pages。PR ではテストとビルドのみ。Vite の `base` は
                                      `/cc_bug_catching/`
  --------------------------------------------------------------------------------------------------------------------------------------------------

> GitHub のリポジトリ設定 → Pages → Source を「GitHub
> Actions」にする必要がある。

## 2. 画面構成

1.  **タイトル**:
    夏の森の背景（虫が飛び回るデモ）、ロゴ「むしとり」、「TAP TO
    START」、ハイスコア。
2.  **プレイ**: 下記。
3.  **リザルト**:
    合計スコア、ハイスコア更新表示、捕まえた虫の内訳（アイコン×匹数と小計）。表示から約
    1
    秒後以降、画面のどこをタップしてもタイトルへ戻る（連打の勢いで誤って戻らないように待つ）。

## 3. プレイ画面

### 3.1 レイアウト（1 画面固定・スクロールなし）

-   背景: 夏の雑木林。奥に空、木々、低木、草むらが見える。
-   上部: 木の枝や葉、空中を飛ぶ虫。
-   中部: 木の幹、低木、花など。幹にとまる虫や周囲を飛ぶ虫。
-   下部: 草むらと地面。主人公が虫取り網を持って立つ。
-   時間帯に応じて背景全体を **昼 → 夕方 → 夜** に変化させる。
-   下部: 操作パネル。丸いボタン 1
    つのみ。ただし画面のどこをタップ・長押ししても、このボタンと同じ操作になる。
-   HUD: 左上に残り時間、右上にスコアとミュートボタン。

### 3.2 ゲームの流れ

-   制限時間 **90 秒**。
-   90 秒の中で時間帯が **昼 → 夕方 → 夜** と変化する。
-   ゲーム開始時から虫はそれぞれ固有の動きで画面内を移動する。
-   プレイヤーは虫の位置と移動を見ながら、長押しで虫取り網を振りかぶり、狙ったタイミングで指を離して網を振る。
-   網と虫が重なればその場で捕獲成功。捕獲後の追加操作や捕獲バトルは存在しない。
-   捕獲した虫の得点を加算し、新しい虫を一定時間後に補充する。
-   制限時間終了時点でリザルトへ移行する。

### 3.3 虫取り網の操作

-   **押していない状態**: 主人公は網を通常位置に構える。
-   **長押し開始**: 主人公が網を後方へ振りかぶり始める。
-   **長押し中**:
    振りかぶり量が徐々に大きくなる。同時に網を振った際の到達距離が伸びる。
-   **指を離す**: その時点の振りかぶり量に応じた軌道で網を一気に振る。
-   短い長押しでは主人公に近い位置、長い長押しでは遠い位置まで網が届く。
-   最大まで振りかぶった後は、それ以上長押ししても到達距離は増えない。
-   網を振っている最中は次の入力を受け付けない。
-   振り終わると短い硬直時間を挟み、通常の構えへ戻る。
-   操作は「長押し → 離す」のみとし、スワイプや方向入力は使用しない。

### 3.4 捕獲判定

-   網を振った際、**網の輪の内側**と虫の当たり判定が重なった瞬間に捕獲成功とする。
-   網の柄には捕獲判定を持たせない。
-   虫の当たり判定は見た目より少し小さくし、理不尽な判定を避ける。
-   1 回のスイングで捕獲できる虫は原則 **1 匹**。
-   複数の虫が同時に網へ入った場合は、網の中心に最も近い虫を捕獲する。
-   網を外した場合はそのまま空振りとなり、ペナルティは振り終わるまでの時間ロスのみ。
-   捕獲した虫は即座に画面から消える。

### 3.5 捕獲成功

-   捕獲成功時、網の中に虫が入った状態で約 **0.4 秒**静止する。
-   小さなヒットストップ、効果音、振動で手応えを出す。
-   その後、虫を画面中央へ拡大表示する短い GET 演出へ移行する。
-   GET 演出後はすぐ通常プレイへ戻る。
-   捕獲バトル、ゲージ操作、虫が網から逃げる処理は設けない。

### 3.6 GET 演出

-   約 **1.0 秒**。テンポを損なわない短い演出とする。
-   捕獲した虫のドット絵を中央に拡大表示。
-   「カブトムシ GET!! +100pt」のように虫名と獲得点を表示。
-   高得点・レアな虫ほど画面フラッシュ、集中線、レア度表示を追加する。
-   演出中はゲームタイマーを停止する。
-   タップでスキップ可。ただしスキップ操作を次の網操作として扱わない。

## 4. 時間帯

### 4.1 フェーズ

90 秒のプレイ時間を 3 フェーズに分ける。

  時間        フェーズ   見た目
  ----------- ---------- ----------------------------------------
  90〜61 秒   昼         青空。明るい緑の森。強い日差し
  60〜31 秒   夕方       オレンジ色の空。木々に長い影
  30〜0 秒    夜         紺色の空。暗い森。月明かりとホタルの光

-   フェーズ切替時に画面を急変させず、数秒かけて背景色とライティングを補間する。
-   フェーズによって虫の出現テーブルを変更する。
-   昼にしか出ない虫、夜に出やすい虫を設け、時間経過そのものをゲーム展開の変化にする。
-   夜でも虫と網の位置が判別できる明るさを維持する。

## 5. 虫

### 5.1 行動

虫ごとに移動パターンを変え、**捕獲難易度は主に虫の動きによって作る**。

-   画面内には常時複数の虫を出現させる。
-   捕獲された虫、または画面外へ完全に出た虫は消え、一定時間後に新しい虫を補充する。
-   虫ごとに速度、移動方向、停止時間、方向転換頻度、上下動、急加速などのパラメータを持つ。
-   高得点の虫ほど単純に高速化するのではなく、固有の動きからタイミングを読む必要がある設計にする。
-   プレイヤーの入力に反応して逃げる仕組みは基本的に設けず、見えている動きを読んで捕獲できるゲームにする。

### 5.2 基本的な移動パターン

  ---------------------------------------------------------------------------------------------
  パターン                動き                                       主な虫
  ----------------------- ------------------------------------------ --------------------------
  歩行                    地面や枝を一定方向へゆっくり進む           ダンゴムシ、テントウムシ

  跳躍                    静止・歩行の後、突然大きく跳ぶ             バッタ

  静止→飛翔               木に長くとまり、突然飛び立つ               セミ、カブトムシ

  蛇行                    上下左右へ緩やかに方向を変えながら飛ぶ     モンシロチョウ、アゲハ

  ホバリング              一定位置付近に留まりながら細かく移動する   ホタル

  高速直線                画面を高速で横切り、短時間しか狙えない     オニヤンマ

  急旋回                  高速移動しながら不規則に進行方向を変える   タマムシ
  ---------------------------------------------------------------------------------------------

### 5.3 虫種表

得点は捕獲難易度・出現率・出現時間の短さを基準に設定する。

  主な時間帯   虫                 行動                                     得点
  ------------ ------------------ -------------------------------------- ------
  昼           ダンゴムシ         地面をゆっくり歩く                         10
  昼           テントウムシ       草や枝をゆっくり移動                       15
  昼           モンシロチョウ     ゆるく蛇行して飛ぶ                         20
  昼           バッタ             静止と大きな跳躍を繰り返す                 30
  昼           セミ               木に静止し、ときどき飛ぶ                   40
  昼・夕方     カマキリ           ゆっくり移動し、ときどき素早く動く         50
  昼・夕方     アゲハ             大きく上下に蛇行して飛ぶ                   60
  夕方・夜     カブトムシ         木の周辺を低速移動、ときどき飛ぶ          100
  夕方・夜     ノコギリクワガタ   木の幹を移動、ときどき停止                120
  夕方・夜     ミヤマクワガタ     木の周辺を移動。出現率が低い              150
  夜           ホタル             発光しながら不規則にホバリング             80
  昼・夕方     オニヤンマ         高速で画面を横切る                        180

  夜           オオクワガタ       出現率が非常に低く、短時間で移動する      300

### 5.4 出現バランス

-   常時の虫の数は標準の 360px 幅で **約 6〜8 匹**。
-   横長画面では表示幅に比例して虫を増やし、密度を維持する。
-   低得点の虫は頻繁に出現し、網操作の練習対象になる。
-   高得点の虫は出現率を下げるか、画面内にいる時間を短くする。
-   同じ虫だけを狙い続けるのが最適解にならないよう、時間帯ごとに出現率を変化させる。

## 6. ゲーム性の基本方針

-   プレイヤーが判断する要素は
    **「どの虫を狙うか」「いつ離すか」「どれだけ振りかぶるか」** の 3
    点に絞る。
-   操作難度を追加のゲージやミニゲームではなく、虫の移動パターンと網の到達タイミングによって作る。
-   長押し時間がそのまま捕獲距離になるため、近い虫には短く、遠い虫には長く溜める。
-   長く溜めるほど捕獲範囲が広くなる仕様にはしない。遠距離の虫ほど未来位置を予測する必要があり、自然に難しくなるようにする。
-   レアな虫を見つけた際に「今の狙いを捨てて狙うか」という瞬間的な判断が発生する出現バランスにする。
-   捕獲成功後の操作は設けず、狙って網を振る瞬間そのものをゲームの中心にする。

## 7. 調整用定数

網の振りかぶり時間、最大到達距離、スイング速度、硬直時間、捕獲判定サイズ、虫ごとの移動速度・停止時間・方向転換頻度・出現率・得点、時間帯ごとの出現テーブルなどは、すべて
`src/config.ts` と `src/bugs.ts`
に定数としてまとめ、後から調整できるようにする。
