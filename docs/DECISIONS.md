# 仕様の補足・決定事項

`docs/SPEC.md` を実装するにあたり、仕様で未定義・曖昧だった点を以下のとおり決めた。
数値はすべて `src/config.ts` / `src/bugs.ts` で調整できる。

## 技術・デプロイ

| 項目 | 決定 |
|---|---|
| Vite の `base` | `/cc_bugcatching/`（リポジトリ名に合わせる。SPEC の `/cc_bug_catching/` から変更） |
| ブランチ運用 | `main` を初期化し、作業ブランチから PR |
| ツール | npm + Node 24 LTS（`.nvmrc`） |
| CI | PR / `main` とも 型チェック → Vitest → ビルド → Playwright スモーク。`main` への push のみ Pages へデプロイ |
| フォント | Google Fonts の DotGothic16。最大 3 秒待ち、読めなければシステムフォント |
| テスト | ゲームロジックの Vitest ＋ Playwright スモークテスト（スマホ縦・PC 横） |

## 画面

- 内部幅 = clamp(640 × 画面の横/縦, 360, 1138)。9:16 より縦長なら幅 360 で上下を端の色で延長、16:9 より横長なら左右に帯。
- HUD（残り時間・時間帯・スコア・ミュート）と丸ボタンは **実画面の端**（セーフエリア考慮）に寄せる。ゲーム本体は 640 の領域内。
- ドット絵は虫 16px（オニヤンマは 24×16）を 2 倍で表示（画面上 32px）、主人公 24×32。

## 網

- 方向入力がないため、網は **主人公の真上** へ伸びる。振りかぶり量で高さ（距離）が決まる。
- 伸縮する柄で表現し、溜め中は到達点に薄い輪のマーカーを表示（最大で黄色）。
- 判定は振り下ろしの途中（進行度 35% 以降）〜到達点での静止中。
- 到達までの時間は距離に応じて 0.15〜0.35 秒。
- 初期値: 最大溜め 2.0 秒 / 到達距離 40〜460px / 到達点での静止 0.3 秒 / 硬直 0.2 秒 / 輪の半径 30px / 虫の判定は見た目いっぱい（100%）。
- 硬直明けに押し続けていれば、その時点から溜め始める（溜め時間は準備完了から数える）。

## 捕獲・GET 演出

- 捕獲直後 0.4 秒の静止と GET 演出の間は、ゲーム世界とタイマーを止める。
- レア度は得点で ★1（〜40）/ ★2（50〜100: 軽いフラッシュ）/ ★3（120〜200: フラッシュ＋集中線＋「レア!」）/ ★4（300: さらに「超レア!!」）。
- GET 演出のスキップに使った押下、および演出前から押していた指は「消費済み」とし、一度離すまで網の溜めにならない。

## 虫の出現

- 時間帯が変わると、その時間帯に出ない虫は数秒のうちに画面外へ退場する。
- 中央（主人公の真上）に必ず木の幹を置き、幹にとまる虫も狙えるようにする。飛び移りや歩行で虫が中央の列を横切る。
- 常時の虫の数は幅 360 で最大 8 匹（補充待ちがあるため実際は 6〜8 匹）、幅に比例して増やす。

## その他

- ミュートは初期状態で音あり。設定は localStorage に保存。タイトルにもミュートボタンを置く。キーボードの M でも切替。
- ページが非表示になったら自動で一時停止し、「TAP TO RESUME」で再開（再開のタップは網操作にしない）。
- PC はマウスとスペースキー（長押し）で操作できる。
- リザルトは全 14 種を表示し、今回捕まえていない種はシルエットで名前も「？？？」にする。

## 3 歳児向けの難易度調整

対象を 3 歳児とし、操作をやさしくした。

- 虫を 2 倍の大きさで表示し、当たり判定を見た目いっぱいに広げた（`BUG_SCALE`, `BUG_HIT_SCALE`）。
- 網の輪を半径 14px → 30px にした。
- 最大まで溜める時間を 1.0 秒 → 2.0 秒にし、離すタイミングが 0.2 秒ずれても輪の大きさの範囲に収まるようにした。
- 到達点で網が 0.3 秒止まり、その間に飛び込んできた虫も捕まえられる。判定は振り下ろしの途中から有効。
- 虫の動きを全体に 0.6 倍の速さにした（`BUG_SPEED_SCALE`）。オニヤンマとタマムシは個別にさらに遅くした。

## 虫の登場と中央レーン

待ち時間を減らすため、主人公の真上（中央レーン）を虫がよく横切るようにした。

- 新しく出る虫の 75% は画面端ではなく、中央から 50〜200px 離れた草むらや木の裏からフェードインして現れる（近くに木があれば幹の位置から）。オニヤンマだけは常に画面端から横切る。
- 滞在中の虫は中央から画面幅の 1/3 以内を行き来する（`SPAWN.roamRatio`）。
- 木から飛び立つ虫は 60% の確率で中央の木へ移る。オニヤンマが空中で止まる位置は中央付近。
- 補充までの時間を 0.8〜2.2 秒 → 0.3〜1.0 秒にした。時間帯の切替で退場する虫は数に入れず、去っていく間に交代の虫を出す。

90 秒のシミュレーション（5 回平均）での比較:

| 画面 | 中央レーンに虫が入る回数 | 3 秒以上だれもいない時間 |
|---|---|---|
| スマホ（幅 360） | 27 回 → 39 回 | 8.0 秒 → 1.0 秒 |
| 横長（幅 1138） | 30 回 → 64 回 | 16.0 秒 → 0.5 秒 |

## 操作方法の変更（タップ＋ゲージ）

長押しを受け付けない端末があるため、長押しを離すタイミングに頼らない操作にした。

- **タップ**（0.2 秒以内に離す）: すぐに最小距離（主人公のすぐ上）へ網を振る。
- **0.2 秒を超えて押す**: 少年の横にゲージが出る。ゲージは 空 → 満タン → 空 と 2 秒で往復し、**もう一度押した時点のゲージ量**で届く距離が決まる。長押しを離しても、途中で途切れても、ゲージは表示されたまま待つ。
- 溜め中は届く位置に点線の輪を表示し、ゲージが満タンで合図音が鳴る。
- 振り終わったあと、押しっぱなしでは次の操作にならない（新しく押す必要がある）。
- 調整用定数: `NET.tapTime`（0.2 秒）, `NET.gaugePeriod`（2 秒）, `GAUGE`（ゲージの大きさ）。
